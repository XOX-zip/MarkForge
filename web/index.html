标题

MarkForge

专注书写的 Markdown 工作台

Version 1.1 Author · MarkSkecher

一个零依赖、单页运行的 Markdown 编辑器。界面借鉴专业软件的分区布局， 却始终保持轻盈、克制与舒适。所有数据只在本地处理，从不上传。

核心能力

自研解析器

支持标题、嵌套列表、表格、任务列表、引用、代码块、折叠块与高亮。

语法着色

内置轻量高亮器，识别 JS / TS / Python / HTML / CSS 等十余种语言。

流畅滚动

缓存布局尺寸 + 帧级锁，编辑与预览同步滚动顺滑如丝，无抽搐。

文件保存

内容不再自动存本地；按 Ctrl+S 导出 .md 即视为保存，若尚有未保存修改，关闭页面时浏览器会提醒你。

命令面板

Ctrl + P 唤出，模糊搜索全部操作，键盘流用户的福音。

导出

一键保存 .md 源文件，或导出带完整样式的独立 HTML 页面。

技术栈

  • 渲染引擎Vanilla JS · 无第三方依赖
  • 高亮方案按语言预编译正则 + LRU 缓存
  • 滚动同步缓存尺寸 + isSyncing 锁 + 双层 rAF
  • 主题系统CSS 变量 + prefers-color-scheme

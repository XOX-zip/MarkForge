# MarkForge

一个专注书写的专业级 Markdown 在线编辑器，由 MarkSkecher 设计与开发。

MarkForge 是一个零依赖、单页运行的 Markdown 编辑器。界面借鉴专业软件的分区布局，却始终保持轻盈、克制与舒适。所有数据只在本地处理，从不上传。

---

## 简介

MarkForge 把「写」和「看」放在一起。左侧敲 Markdown 源码，右侧实时渲染成排版精美的文档。它不需要安装、不需要构建、不需要联网，打开 `index.html` 就能用。整个项目由三个文件组成：`index.html`、`styles.css`、`app.js`，没有任何第三方依赖。

它的目标只有一个——让你专注于内容本身。

---

## 核心特性

**双栏实时预览。** 左侧编辑源码，右侧立即渲染。拖动中间的分隔条可以自由调整两栏的比例，也可以一键切换到「仅编辑器」「分栏」「仅预览」三种布局。

**同步滚动。** 编辑区与预览区的滚动位置按比例映射，无论文档多长，两边始终保持对齐。为了做到顺滑无抽搐，滚动同步采用了缓存尺寸加帧级驱动锁的方案：谁在驱动滚动，持锁窗口内另一栏的回声事件就被忽略。程序化滚动一律即时执行，绕过 CSS 的平滑动画，避免回灌。

**自研 Markdown 解析器。** 支持 1–6 级标题、段落、引用、分隔线、围栏代码块、表格、有序列表、无序列表、嵌套列表、任务清单、超链接、图片、行内代码，以及加粗、斜体、删除线、高亮等文本格式，还支持原生 `<details>` 折叠块。

**语法高亮。** 内置轻量高亮器，无第三方依赖。支持 JavaScript、TypeScript、Python、Ruby、Bash、YAML、HTML、CSS、JSON、Markdown、SQL、Go、Rust、Java、C、C++ 等十余种语言。按语言预编译正则数组，顺序敏感处理，注释和字符串优先匹配；使用 LRU 缓存避免重复解析；超长代码会自动降级为纯文本，保证性能。

**命令面板。** 按下 `Ctrl + P` 唤出，模糊搜索全部操作，按文件、格式、插入、视图、主题、帮助分类展示。对键盘流用户非常友好。

**文档大纲。** 左侧面板自动生成标题导航，点击任意标题即可跳到对应位置。

**实时统计。** 右侧面板显示字数、字符数、行数、段落数、标题数以及预计阅读时长。状态栏还会实时显示光标所在的行、列，以及当前选中的字符数。

**主题系统。** 支持浅色、深色、跟随系统三种模式，另有六种强调色（蓝、紫、粉、橙、绿、青）可选。主题基于 CSS 变量实现，切换无闪烁，首屏加载前即已应用。

**文件操作。** 按 `Ctrl + S` 保存为 `.md`，按 `Ctrl + Shift + S` 导出带完整样式的独立 HTML 页面，也可以打开本地的 `.md`、`.markdown`、`.txt` 文件。文档内容不再自动保存到本地，若关闭页面前尚有未保存修改，浏览器会提醒你。

## 快速开始

MarkForge 是纯静态单页应用，无需构建、无需安装依赖。

直接克隆仓库，双击 `index.html` 即可运行。也可以用本地服务器打开，例如运行 `python -m http.server 8000` 或 `npx serve .`，然后访问 `http://localhost:8000`。

项目目录结构如下：

```
MarkForge/
├── index.html    # 页面结构
├── styles.css    # 样式表
├── app.js        # 应用逻辑
├── LICENSE       # 开源许可证
└── README.md
```

## 快捷键

编辑相关：`Ctrl + B` 加粗，`Ctrl + I` 斜体，`Ctrl + K` 插入链接，`Ctrl + Z` 撤销，`Ctrl + Y` 重做，`Tab` 增加缩进，`Shift + Tab` 减少缩进。

文件相关：`Ctrl + N` 新建文档，`Ctrl + O` 打开文件，`Ctrl + S` 保存为 `.md`，`Ctrl + Shift + S` 导出 HTML。

视图相关：`Ctrl + P` 打开命令面板，`Ctrl + 1` 仅编辑器，`Ctrl + 2` 分栏，`Ctrl + 3` 仅预览，`Ctrl + Shift + B` 切换右侧面板，`F11` 全屏，`Esc` 关闭弹窗或面板。

## Markdown 语法速查

文本样式用 `**粗体**`、`*斜体*`、`~~删除线~~`、`==高亮==`、`` `行内代码` ``。

标题用 `#` 到 `######`，引用用 `>`，分隔线用 `---`，折叠块用 `<details>` 和 `<summary>`。

列表用 `-` 表示无序，`1.` 表示有序，`- [ ]` 和 `- [x]` 表示任务清单的未完成与已完成。

链接写作 `[文字](url)`，图片写作 `![描述](地址)`。

代码块用三个反引号包裹，并在起始处标注语言，例如 ```` ```javascript ````。

表格用竖线分隔列，第二行用 `---` 控制对齐。

## 技术实现

渲染引擎使用原生 JavaScript，无任何第三方依赖。语法高亮采用按语言预编译正则数组加 LRU 缓存的方案。滚动同步使用缓存尺寸、驱动锁与即时滚动。主题系统基于 CSS 变量与 `prefers-color-scheme` 媒体查询。渲染节流通过时间片合并与 `requestAnimationFrame` 实现。用户设置保存于 `localStorage`，文档内容不入本地存储。

## 可配置项

右侧面板提供丰富的编辑器设置：编辑器字体（等宽、系统、衬线）、Tab 宽度（2、4、8）、字号（11 到 20 像素）、行高（1.3 到 2.4）、预览宽度（560 到 1400 像素，1400 表示铺满）、渲染节流（0 到 200 毫秒）、同步滚动、自动换行、显示行号、拼写检查、平滑滚动等开关。所有设置保存于浏览器本地，可通过「恢复默认设置」一键重置。

---

## 浏览器支持

推荐使用现代浏览器：Chrome 或 Edge 90 以上、Firefox 88 以上、Safari 14 以上。需要支持 CSS 自定义属性、Pointer Events、matchMedia、requestAnimationFrame 等特性。
